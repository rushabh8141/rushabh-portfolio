# Rushabh Pande Portfolio

This is a lightweight personal portfolio built with plain HTML and CSS. It features
navigation links, a hero banner and sections for education, experience, skills,
projects and contact details.

The site can be deployed on any static hosting provider (e.g. GitHub Pages).

## Sections
- Hero intro
- About with profile photo and social links
- Education & Experience
- Skills
- Projects
- Contact info and CV download
